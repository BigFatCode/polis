# Telegram as a low-cost playtest interface

**Status:** Parked.

## Motivation

Use a Telegram bot or chat interaction to test collective proposals and decisions without investing heavily in a game UI. This is an experiment-delivery idea, not an implementation milestone.

## Revisit when

The next experiment has a defined hypothesis and needs an inexpensive way for people to participate. Evaluate whether chat interactions can expose the behavior being tested and whether participants can practically use them.

## Questions if activated

- Which interactions must the experiment support, and can participants understand them in chat?
- What observations would distinguish useful coordination from voting fatigue?
- What state and decision history must the experiment retain?
- How much work would this save compared with the other available interfaces?

These questions become scoped decision tickets only when this idea enters an active effort. No bot or platform-specific architecture is selected here.
