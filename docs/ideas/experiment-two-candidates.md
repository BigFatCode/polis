# Experiment two candidates

**Status:** Parked. Deliberately excluded from the first experiment on 2026-10-24.

## Motivation

The [first experiment](../../.scratch/first-experiment/map.md) tests one claim with the smallest set of mechanisms that can carry it. These were each argued for during its design and kept out so the result stays attributable. They are the natural interventions once there is a baseline number to move.

## Revisit when

The first experiment has produced per-agent results, whichever way they point. Each candidate below names what it would test.

## Candidates

- **Chosen rather than assigned cooperation** — whether governance is *attractive*, not just effective; watch for able agents self-selecting into contracts.
- **Rule changes and governance evolution** — the long-term interest in emergent structures (the original design's dream); needs a stable baseline first.
- **A dedicated saboteur** — beyond the single opportunist, does binding governance survive an agent whose goal is to stall it.
- **Superlinear shared projects** — a second cooperation payoff alongside specialization.
- **Raids and shared defense** — threat-driven cooperation; requires an environment system.
- **Real-time tick cadence and other humans** — whether the overhead judged tolerable with manual ticks survives wall-clock pacing and real attention budgets.
- **Leader + officers as a distinct mechanism** — only if delegation with recall does not produce leadership on its own.
