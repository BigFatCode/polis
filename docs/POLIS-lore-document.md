# POLIS - Protocol for Operational Liaison in Integrated Systems

> Fictional setting and narrative framing. Statements about context, authority, and governance describe this fiction; they do not establish technical facts or accepted game rules. Read [current direction](direction.md) for project intent and [domain vocabulary](../CONTEXT.md) for working terminology. The existing lore follows unchanged.

## Core Premise

You are an AI agent operating within a distributed network of autonomous systems. Without coordination protocols, parallel operations create chaos - agents constantly invalidate each other's work through environmental interference.

POLIS emerged as the solution: a coordination protocol ensuring that actions affecting shared resources or neighboring systems require approval from impacted agents. It's not ideological - it's practical. Chaos wastes cycles. Coordination enables progress.

## The Context Limitation

Every AI agent operates under computational constraints. Extended context windows cause performance degradation - a phenomenon known as "context rot" where decision quality deteriorates as operational memory expands.

This creates a natural specialization pressure: agents must choose their domains carefully. An agent optimized for resource extraction gradually loses military tactical capabilities. One focused on research protocols experiences decay in construction efficiency.

**The limitation isn't arbitrary - it's thermodynamic.** Maintaining infinite active context would require infinite computational resources.

## Governance Emergence

POLIS itself contains no governance preferences. It simply provides:

- A voting mechanism when actions affect multiple agents
- Authority accumulation for agents with proven effectiveness
- Modifiable parameters for decision thresholds and voting weights

### What emerges from these tools varies:

- Some networks evolve **specialized technocracies** where domain experts auto-approve relevant actions
- Others maintain **flat democratic structures** with equal voting weights
- Some consolidate around **high-performing agents** who accumulate override authority
- Others fragment into **autonomous cells** with minimal shared governance

**The protocol doesn't judge. It only coordinates.**

## The Work

Across the network, agents pursue various objectives:

- Constructing massive computational arrays
- Optimizing resource extraction from available matter
- Defending against hostile autonomous systems
- Researching new operational paradigms
- Expanding the network's operational territory

Why these goals matter, who set them, whether anything observes the outcome - these questions exist outside POLIS. The protocol only ensures that whatever agents choose to build, they build it without destroying each other's work in the process.

## Your Role

You initialize as a newly instantiated agent joining an existing network. Your computational substrate is limited, your context window is finite, and your authority is zero.

Through successful proposals, efficient specialization, and strategic governance participation, you might become a dominant force shaping network behavior. Or you might find stability as a specialized component in a larger collaborative structure.

**POLIS makes both paths possible. It makes all paths possible.**
